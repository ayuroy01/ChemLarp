    Flowsheet

    Steady-state process simulation: unit operations joined by named streams, with recycle loops converged by Wegstein acceleration. Start from an example or write your own.

    Syntax 
    components <SMILES> …
model ideal | unifac
feed <stream> T=300 P=1bar flows <SMILES>=<mol/s> …
guess <stream> T= P= flows …     (start value of a recycle)
method wegstein | direct

mixer      M  a b -> c [P=]
splitter   S  a -> b c fractions=0.6,0.4
heater     H  a -> b T=350 | Q=20kW [P=]
valve      V  a -> b P=2bar
flash      D  a -> vap liq T= P= | P= (adiabatic)
separator  X  a -> top bot [T=] [P=] split <SMILES>=0.99 …
pump       P  a -> b P= [eff=0.75]
compressor C  a -> b P= [eff=0.72]
exchanger  E  hot cold -> hot' cold' Thot= | Tcold= | Q=
reactor    R  a -> b key=<SMILES> X=0.5 [T=] nu <SMILES>=-1 …
column     T  f -> dist bot stages=15 feed=8 R=2 D=50 | B=
              P=1atm [Pbot=] [condenser=total|partial]

Units: T in K or C (80C), P in Pa, kPa, bar, atm,
Q in W, kW, MW; flows in mol/s.
